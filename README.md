  # Carlson's Smart Clock

  ### A clock you build and control yourself.

  Thirteen colourful faces on a 64 × 32 LED matrix, with settings served by
  the clock on your own network. No cloud account or subscription is needed
  for the clock itself.

  [Software and downloads](https://github.com/LORDSn1per/Carlsons-Smart-Clock-Software) ·
  [Hardware and build guide](https://github.com/LORDSn1per/Carlsons-Smart-Clock-Hardware) ·

The project has grown into two repositories, following the same structure as
OpenRemote:

| Go here | For |
|---|---|
| [**Carlson's Smart Clock — Software**](https://github.com/LORDSn1per/Carlsons-Smart-Clock-Software) | Current firmware, source history, locally hosted settings page, Clock Builder for Mac and Windows, and the [latest downloads](https://github.com/LORDSn1per/Carlsons-Smart-Clock-Software/releases/latest) |
| [**Carlson's Smart Clock — Hardware**](https://github.com/LORDSn1per/Carlsons-Smart-Clock-Hardware) | Parts list, Rev 1.7 PCB manufacturing files and the [step-by-step build guide](https://github.com/LORDSn1per/Carlsons-Smart-Clock-Hardware/blob/main/BUILD_GUIDE.md) |
| [**MakerWorld print profile**](https://makerworld.com/en/models/1593477-p2-5-matrix-smart-clock#profileId-1678436) | Current enclosure, diffuser and printable parts |

This original repository remains available so existing links keep working. The
`MyClock_2.xx.ino.bin` files and PCB ZIP here are **historical uploads**; use
the software repository's latest release for a new build. The complete local
Git development history is in the software repository.

The clock's display and settings are controlled locally. Wi-Fi time sync and
live weather are optional network features; weather providers may require an
API key and have their own limits or pricing. The product photo is from my
[MakerWorld listing](https://makerworld.com/en/models/1593477-p2-5-matrix-smart-clock#profileId-1678436).
